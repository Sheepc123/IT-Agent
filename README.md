# 企业 IT 资产管理与采购决策 Agent 平台

围绕办公与开发设备、AI 研发基础设施两类采购，建设资产复用、技术证据调查、方案比较与采购执行平台。

采用数据中台、RAG 和评测中台作为共享底座，使用确定性 Workflow 控制业务流程，在复杂分析中引入有限范围的 Agent 调查。

## 当前状态

项目处于计划基线阶段。本次已建立项目计划与变更记录约定；应用代码、数据库、演示数据和评测集尚未创建。
