# 企业 IT 资产管理与采购决策 Agent 平台

围绕办公与开发设备、AI 研发基础设施两类采购，建设资产复用、技术证据调查、方案比较与采购执行平台。

采用数据中台、RAG 和评测中台作为共享底座，使用确定性 Workflow 控制业务流程，在复杂分析中引入有限范围的 Agent 调查。

## 当前状态

P01 已完成业务需求、角色权限与 32 个验收故事的文档基线；P02 已完成领域模型、状态机和接口契约的设计基线及文档一致性检查；P03 已完成 40 条种子评测规格（仅规格：未经第二人复核，尚无 fixture、判定器或运行结果）。已有 React/Next.js/TypeScript/pnpm 前端及 Python/uv 后端初始化骨架；业务功能、数据中台、RAG 和评测仍待实现，本轮未验证应用运行。

当前 `.gitignore` 忽略 `docs/` 和 `scripts/`，其中需求文档与日志为本地交付，尚未纳入 Git 跟踪。

首版采购推荐已确定：输入需求后从维护好的目录推荐型号和模拟店铺/报价；技术依据来自经核对的真实厂商资料。普通表单不调用生成模型，自然语言每次提交最多一次解析，复杂问题再按预算调查。该方案已写入文档，尚未实现，不接实时电商或自主网页购物。
